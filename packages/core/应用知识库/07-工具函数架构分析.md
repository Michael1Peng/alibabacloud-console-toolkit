# 工具函数架构分析

## 概述

`@alicloud/console-toolkit-core` 的工具函数提供了各种辅助功能，支持插件解析、预设处理、文本格式化等核心功能。这些工具函数采用了函数式编程的理念，提供了可复用、可测试的工具集合。

## 核心工具函数分析

### 1. 文本格式化工具

#### getPadLength.ts - 计算填充长度

```typescript
export default function getPadLength(obj: Record<string, any>) {
  let longest = 10;
  for (const name in obj) {
    if (name.length + 1 > longest) {
      longest = name.length + 1;
    }
  }
  return longest;
}
```

**功能分析：**
- **用途**：计算对象键名的最大长度，用于格式化输出
- **最小值**：设置了 10 作为最小填充长度
- **算法**：遍历所有键名，找出最长的长度并加 1
- **应用场景**：帮助命令的格式化输出、配置选项的对齐显示

**使用示例：**
```typescript
const commands = {
  'build': { description: '构建项目' },
  'dev': { description: '开发模式' },
  'test': { description: '运行测试' }
};

const padLength = getPadLength(commands); // 返回 6 (build + 1)

// 格式化输出
for (const name in commands) {
  console.log(`${name.padEnd(padLength)}${commands[name].description}`);
}
// 输出:
// build  构建项目
// dev    开发模式  
// test   运行测试
```

### 2. 插件解析工具

#### pluginResolver.ts - 插件识别和匹配

```typescript
const pluginRE = /^(@breezr\/|breezr-|@[\w-]+\/breezr-)plugin-/;
const scopeRE = /^@[\w-]+\//;

export const isPlugin = (id: string) => pluginRE.test(id);

export const matchesPluginId = (input: string, full: string) => {
  const short = full.replace(pluginRE, '');
  return (
    // input is full
    full === input ||
    // input is short without scope
    short === input ||
    // input is short with scope
    short === input.replace(scopeRE, '')
  );
};
```

**功能详解：**

#### isPlugin 函数
- **正则表达式**：`/^(@breezr\/|breezr-|@[\w-]+\/breezr-)plugin-/`
- **匹配模式**：
  - `@breezr/plugin-xxx`
  - `breezr-plugin-xxx`
  - `@scope/breezr-plugin-xxx`
- **用途**：判断给定的包名是否为有效的插件

#### matchesPluginId 函数
- **完整匹配**：直接比较完整的插件ID
- **简化匹配**：去掉前缀后比较
- **作用域匹配**：处理带作用域的简化名称

**匹配示例：**
```typescript
// 完整插件名
const fullName = '@alicloud/breezr-plugin-webpack5';

// 以下都会匹配成功
matchesPluginId('@alicloud/breezr-plugin-webpack5', fullName); // true (完整匹配)
matchesPluginId('webpack5', fullName); // true (简化匹配)
matchesPluginId('@alicloud/webpack5', fullName); // true (作用域匹配)
```

### 3. 预设解析工具

#### presetResolver.ts - 预设处理和插件合并

```typescript
function idToPreset(preset: string) {
  let presetId = preset;
  let presetConfig = null;
  if (isArray(preset)) {
    [presetId, presetConfig] = preset;
  }
  return {
    id: presetId.replace(/^.\//, 'built-in:'),
    presetEntry: resolveModule(require(presetId)),
    config: presetConfig || {},
  };
}
```

**功能分析：**
- **输入处理**：支持字符串或数组形式的预设配置
- **ID标准化**：将相对路径转换为内置标识
- **模块解析**：处理 ES6 模块和 CommonJS 模块
- **配置提取**：分离预设ID和配置对象

#### 插件合并函数

```typescript
function mergePluginFromPreset(
  plugin: string,
  pluginMap: Map<string, any>,
  plugins: any[]
) {
  let pluginId = plugin;
  let pluginConfig = null;
  if (isArray(plugin)) {
    [pluginId, pluginConfig] = plugin;
  }
  if (pluginMap.has(pluginId)) {
    // merge plugin config
    if (pluginConfig) {
      Object.assign(pluginMap.get(pluginId), pluginConfig);
    }
  } else {
    plugins.push(plugin);
    pluginMap.set(pluginId, pluginConfig ? pluginConfig : {});
  }
}
```

**合并策略：**
- **去重处理**：使用 Map 跟踪已加载的插件
- **配置合并**：相同插件的配置进行合并
- **顺序保持**：维护插件的加载顺序

#### 预设解析主函数

```typescript
export async function resolvePresets(config: PluginConfig, args: CommandArgs) {
  const { presets, plugins: orginalPlugin } = config;

  const pluginMap = new Map<string, any>();
  const plugins: any[] = [];

  await Promise.all(
    presets.map(idToPreset).map(async preset => {
      const { presetEntry, config } = preset;
      const presetConfig = await (presetEntry(config, args) as PluginConfig);
      presetConfig.plugins.forEach(plugin => {
        mergePluginFromPreset(plugin, pluginMap, plugins);
      });
    })
  );

  orginalPlugin.forEach(plugin => {
    mergePluginFromPreset(plugin, pluginMap, plugins);
  });

  debug('core', 'resolve plugin is %o', plugins);

  return plugins;
}
```

**执行流程：**
1. **并行处理**：使用 `Promise.all` 并行加载所有预设
2. **预设执行**：调用预设函数获取插件列表
3. **插件合并**：合并预设中的插件到总列表
4. **原始插件**：处理配置中直接定义的插件
5. **调试输出**：记录最终的插件列表

### 4. Service 中的工具函数

#### 插件ID转换

```typescript
function idToPlugin(id: string) {
  if (isArray(id)) {
    id = id[0];
  }
  return {
    id: id.replace(/^.\//, 'built-in:'),
    pluginEntry: resolveModule(require(id))
  };
}
```

**功能：**
- **数组处理**：支持 `[pluginId, config]` 格式
- **路径标准化**：相对路径转为内置标识
- **模块解析**：获取插件入口函数

#### 从包依赖解析插件

```typescript
function resolvePluginsFromPkg(pkg: PackageJson) {
  return Object.keys(pkg.dependencies || {})
    .filter(isPlugin)
    .map(idToPlugin);
}
```

**功能：**
- **依赖遍历**：遍历 package.json 中的所有依赖
- **插件过滤**：使用 `isPlugin` 函数过滤出插件包
- **转换处理**：将包名转换为插件对象

// Service.ts 中使用插件解析工具
private resolveBuiltInPlugins(plugins?: any[]): BreezrPlugin[] {
  const builtInPlugins = [
    './plugins/config/config',
    './plugins/common/index',
    './plugins/commands/help'
  ].map(idToPlugin);

  if (!plugins) {
    plugins = [];
  }
  const resolvePlugins = plugins.map(idToPlugin);

  return [...builtInPlugins, ...resolvePlugins];
}
